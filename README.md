# Customer Churn Deep Learning

An End-to-End Deep Learning project built using TensorFlow, Keras, Scikit-learn, and Streamlit.

This repository contains two neural network projects based on the Customer Churn dataset:

- ANN Classification (Customer Churn Prediction)
- ANN Regression (Estimated Salary Prediction)

---

## Features

- ANN Classification Model
- ANN Regression Model
- Streamlit Web Applications
- One-Hot Encoding
- Label Encoding
- Feature Scaling
- TensorFlow/Keras Model
- Interactive Prediction Interface

---

## Installation

```bash
git clone https://github.com/gopalbhargav/Customer-Churn-Deep-Learning.git

cd Customer-Churn-Deep-Learning

pip install -r requirements.txt

streamlit run app.py
```

For Regression:

```bash
streamlit run streamlit_regression.py
```
